# Security Policy

## Reporting a vulnerability

Report vulnerabilities in the tooling privately via GitHub's private vulnerability
reporting: Security tab, then "Report a vulnerability".

For a wrong or unsafe value, open a "Data correction" issue with a citation and the
`fact_id`. If you believe there is immediate risk, report it privately as above.

## Scope

This repository holds reference data and the pipelines that build it. It makes no
network calls during pull-request checks. See the engine SECURITY.md:
https://github.com/WoodinGlass/agri-agronomy-core/blob/main/SECURITY.md
