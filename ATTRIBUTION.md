# Attribution

No third-party sources are included in the K0 empty pack (`sources.csv` and
`datasets.csv` are header-only). This file is regenerated from `sources.csv` and
`datasets.csv` once real data lands (K1 onward).

When present, each source is listed with its license and the attribution text it
requires. See the engine licensing policy:
https://github.com/WoodinGlass/agri-agronomy-core#licensing-policy
